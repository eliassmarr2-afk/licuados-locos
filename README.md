# Licuados Locos — Ecommerce V1

Réplica estructural de la interfaz canónica de `ecommerce-v2`, adaptada al dominio de Licuados Locos.

## Contrato visual

- Mobile-first.
- Ancho máximo de aplicación: 480 px.
- Tipografía Manrope 400/500/600.
- Canvas #ededed.
- Superficies blancas.
- Navegación, estados, formularios, sheets, carrito, seguimiento y soporte conservan la estructura del repositorio fuente.
- Fotografías e imágenes de producto intencionalmente ausentes en esta fase.

## Páginas

- Inicio
- Producto
- Carrito
- Ingresar
- Seguimiento
- Estado de seguimiento
- Soporte

## Datos

El catálogo local está aislado en `js/data/catalog.js` para que pueda sustituirse más adelante por Protocol Data sin rehacer la composición visual.
